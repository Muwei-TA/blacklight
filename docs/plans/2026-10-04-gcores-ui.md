# 黑光网站 UI 改版

用户于 2026-10-04 审核并同意 `/workspace/artifacts/gcores-design-review.html` 中的效果图。

## 目标与约束

将已确认的机核网风格参考应用于黑光现有网站：216 px 白色侧栏、灰白卡片、红色强调、内容网格、文章阅读区、手机底部导航，以及一致的管理台。保持真实内容、角色权限、匿名身份、登录和审核流程；不引入机核网的品牌或素材。预览示例数据不进入应用。

## 实施步骤

1. 将独立设计中的成员端视图和样式接入网站；保持事件委托及路由数据属性，发布入口遵循现有发布权限。更新图标和主题色。将管理台视觉覆盖合并进现有样式。
2. 使用隔离 PostgreSQL 测试数据验证所有 56 个页面和状态，在 1440 px 电脑和 390 px 手机下截图。检查页面错误、横向溢出、弹窗、表单、搜索、收藏、消息、社团切换和后台导航。运行项目检查、lint 与全套单元测试。
3. 对最终差异做独立代码审查，修复重要问题，生成可离线查看的真实页面图册，并提交独立改版分支。沿用已有草稿 PR 交付入口，未经明确要求不合并或部署。

## 审查重点

确保新卡片使用转义后的真实 DTO，不泄漏匿名作者身份；媒体 URL 沿用既有校验；登录、待审、禁发、非成员状态下发布入口正确；所有控件继续保留事件属性；手机长文本和管理台弹窗无溢出；CSS 不依赖外部字体或素材。
