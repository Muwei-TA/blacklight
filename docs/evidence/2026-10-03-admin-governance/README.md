## 已有实际证据

- 原生微信开发者工具复现 `@hg-fs-h1` 未定义导致 WXSS 编译失败；修正为现有 token 后页面正常渲染，开发者工具中的扫码确认及换届按钮已运行。
- 浏览器创建二维码 → 小程序真实 `account/web-login/info/approve` → 浏览器交换 Cookie → 管理工作台。缺 CSRF、错 Origin 被拒绝，交换不能重放，退出后旧 Cookie 不能读取会话。
- 本社团管理读取正常；跨社团名册、审核员名册、平台开发者社团内容读取被拒绝。

- Web 统一审核队列发现 API 不返回 UI 假定的 actions；改按真实队列合同生成决策后，页面内确认框完成一条合成文章审核。

- 预留过期缺陷已在 PG 事务及微信开发者工具重现：A过期后用B仍返回原 pending；修复后实际用B提交新申请成功，A的预留次数归零；取消B申请后B预留次数也归零。
